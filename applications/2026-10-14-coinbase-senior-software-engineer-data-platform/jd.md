## Role (paraphrased from posting)

Data Platform team inside the Platform group builds the systems that centralize Coinbase's internal
and third-party data, serving analytics, machine learning, and end-user experiences. The role owns
design, development, and operation of foundational data services spanning cloud data warehouses,
data lakes, Airflow orchestration, batch (Spark, SQL), streaming (Kafka), query federation, and
real-time event aggregation stores. Also: data integration/processing SDKs for internal teams;
self-service applications for managing, monitoring, and troubleshooting pipelines; data security and
observability (access controls, data quality tracking, cataloging, lineage, usage auditing).

  in production.
- Data security, access control, or data observability systems (cataloging, lineage, or
  quality monitoring).
- Uses generative AI responsibly with human oversight.
